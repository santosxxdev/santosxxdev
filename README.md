## 🎯 نبذة عني

أنا **محمد عبد الفتاح** - مطور تطبيقات جوال بخبرة في بناء حلول متعددة المنصات باستخدام **Flutter** وكذلك تطوير واجهات وأجزاء **Native** باستخدام **Kotlin** و **Java** عند الحاجة لأداء أو تكامل منخفض المستوى. 

أحب كتابة كود نظيف قابل للاختبار، التركيز على تجربة المستخدم، وتسليم تطبيقات جاهزة للإنتاج.  
**أُبني تطبيقات منتجة، قابلة للصيانة، وتجارب مستخدم سلسة تليق بالمنتجات الاحترافية.**
